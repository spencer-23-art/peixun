WORKFLOW

系统核心闭环架构

系统为典型的“云-端”协同多租户模式，确保了信息录入的高效准确和数据的严格物理隔离：

  • 用户注册审核： 客户端工作单位负责人自主注册，管理员后台审核激活后方可登入。
  • 人员信息录入： 各单位负责人录入员工信息并上传照片，系统结合安全考试结果，自动生成门禁包。
  • 门禁权限恢复： 员工中途离场重新返场时，负责人可一键提交门禁恢复申请，由管理员批量审核更新。

MODULE 01

移动端新用户注册

提供工作单位负责人使用的自主注册界面，兼容 iOS / Android 移动端键盘布局。

  • 键盘友好（iOS优化）： 手机号输入自动过滤非数字，彻底解决了 iOS 系统在 pattern 属性限制下造成的“中文键盘黏滞、无法切换”的痛点。
  • 防重注册校验： 手机号作为唯一登录账号，后端进行防重性检测。
  • 管理审核激活： 注册数据提交后会进入待审核队列，管理员激活后生效。

MODULE 02

员工信息与照片录入

通过桌面管理端录入各单位受训员工的基本信息并生成个人门禁权限：

  • 身份证智能校验： 录入身份证号时，系统前端自动解析合法性，自动计算并填充出生日期，防止手工输入错漏。
  • 免冠照片直观预览： 必须上传真实证件照片。系统进行实时无刷新图片加载与缩放裁切预览。
  • 在线二维码生成： 录入成功并答题合格后，即可直接获取印有员工头像、身份信息的“专属门禁二维码通行证”。

MODULE 03

门禁数据管理与恢复

管理员后台（Admin 面板）提供了高度可视化的门禁数据管理模块：

  • 一键批量导出 (CSV+照片)： 自动按筛选条件将员工信息转换成门禁设备匹配的 CSV 格式，并且批量将真实照片重命名为身份证号一并打包压缩（ZIP）下载，极大方便了门禁机器的快速批量导入。
  • 门禁申请恢复管理： 解决现场离场员工二次返场的“门禁权限失效”情况。负责人提交恢复申请，管理员可快速多选并批量导出其门禁恢复包，效率提升 90% 以上。

SUMMARY

系统架构特点与使用

本系统采用极简的现代化后端技术构建，保证了生产环境中运行的高性能与超低资源占用：

  • 高性能后端： 基于 FastAPI (Python) 构建，全异步事件驱动，支持百级高并发无阻塞数据吞吐。
  • 物理安全隔离： 采用 SQLite 轻量级关系数据库，后端基于 Row-Level 业务隔离，用户仅能查看、修改和申请本单位员工的数据，防止数据跨租户泄露。
  • 热重载与快速部署： 容器化部署挂载，Git 静态拉取秒级热生效，维护简单省心。
